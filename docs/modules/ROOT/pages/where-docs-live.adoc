== Topology

* **Product component source** — `connectome-fs` repository, `docs/` + `docs/antora.yml`
* **Docs hub** — this `docs` repository: playbook, supplemental UI, home portal, Pages deploy
* **Website** — `connectome-fs.github.io` marketing/news/blog only; links to `/docs/`

Do not publish a second public Antora site from the product or website repositories.
